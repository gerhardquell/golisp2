# gensym – Eindeutige Symbole für Makros

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** `(gensym)` erzeugt ein garantiert eindeutiges Symbol (z.B. `G__1`, `G__2`) für hygienische Makros.

**Architecture:** Atomarer int64-Zähler in `lib/primitives.go` (threadsafe wegen `parfunc`).
`fnGensym` inkrementiert und liefert `MakeAtom(fmt.Sprintf("G__%d", n))`.
Kein Parser- oder Eval-Eingriff nötig — reines Primitiv.

**Tech Stack:** Go `sync/atomic`, package `lib`
